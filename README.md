# Profil Mahasiswa

## Deskripsi

Project ini dibuat sebagai salah satu tugas mata kuliah **Pemrograman Mobile** menggunakan Kotlin. Aplikasi digunakan untuk menampilkan informasi profil mahasiswa beserta data akademik dengan tampilan yang modern dan sederhana.

---

## Fitur

- Profil mahasiswa
- Informasi akademik
- Foto profil
- Edit profil

---

## Teknologi

- Kotlin
- Android Studio
- Material 3
- Jetpack Compose
